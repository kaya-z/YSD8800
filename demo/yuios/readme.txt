================================================================
 YUI OS Level 1 Demo (on YSD8800)
================================================================

これは YSD8800 で動く OS である YUI OS Level 1 のデモの説明です。

----------------------------------------------------------------
(1) 起動方法
----------------------------------------------------------------

  シミュレーター (emu23) はソースからコンパイルしてください。
  yuios_road2_12_11.bin と disk イメージ disk.img は dist から
  持って来てください。

    $ emu23 yuios_road2_12_11.bin -it --disk disk.img

  ※ フィボナッチ数列計算プログラムのデモは fib_disk.img を
    使用してください。

----------------------------------------------------------------
(2) 起動メッセージ
----------------------------------------------------------------

    YUIOS Booted!
    0YUI> 123MD

----------------------------------------------------------------
(3) コマンド例
----------------------------------------------------------------

  help コマンド

    YUI> help
    run <n>
    ps
    help
    YUI>

  ls コマンド

    YUI> ls
    hello.txt
    1/1

  cat コマンド

    YUI> cat hello.txt
    Hello, YUI OS!

  run コマンド

    YUI> run fib.bin
    F55YUI>

  ※ 実行ファイルでないものを run すると OS が落ちます。
