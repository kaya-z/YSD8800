============================================================
自作8bit CPU ISA v1.1 FINAL
============================================================

[概要]
- データ幅        : 8 bit
- アドレス空間    : 64 KB (16 bit)
- エンディアン    : Big Endian (abs16 = hi, lo)
- 命令長          : 固定 4 バイト
- 実行モデル      : 観測上 1命令 = 1クロック
- 副作用発生点    : 命令境界のみ

[レジスタ]
A        : 8 bit  (アキュムレータ)
PC       : 16 bit (プログラムカウンタ)
PSW      : 内部 (Z/N/C 将来拡張)
IRQ_EN   : 1 bit (割り込み許可)
PC_SAVED : 16 bit (RTI用)

[メモリ]
ROM : 同期読み出し
RAM : 同期 R/W
I/O : メモリマップト

[割り込み]
- IRQ は命令境界 (FETCH0) でのみ受付
- 非ネスト
- 割り込みベクタ : 0xFFF0
- 割り込み中は IRQ_EN = 0
- RTI で復帰

[命令フォーマット]
+--------+--------+--------+--------+
| opcode |  op1   |  op2   |  op3   |
+--------+--------+--------+--------+

[命令一覧]

-- 転送 --
NOP              opcode 00
LDA #imm8        opcode 10
LDA abs16        opcode 11 (pending load)
STA abs16        opcode 20

-- 制御 --
JMP abs16        opcode 30 (pending PC)
BEQ disp8        opcode 40 (Z=1 なら PC 相対分岐)

-- 割り込み --
CLI              opcode 50
SEI              opcode 51
RTI              opcode 52

-- その他 --
HALT             opcode FF

[タイミング契約]
- LOAD / JMP / BEQ / IRQ は次命令境界で反映
- 成否に関わらず命令実行時間は一定
- 実装は命令バッファ + pending モデル
