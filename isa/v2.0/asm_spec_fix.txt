YSDアセンブラ仕様書 (V2.0)

本仕様書は、CPU YSD8800（ISA2.0準拠）向けのアセンブリ言語の記述ルールを定めるものである。
1. 命令記述形式

アセンブリ言語の1行は、以下の構成で記述する。 [ラベル:] opcode [オペランド1[, オペランド2]]

    opcode（命令）: 1文字以上のスペースまたはタブの後に記述する。

    operand（オペランド）: 命令に応じて、レジスタ、アドレス、即値を指定する。

    区切り文字: オペランドが2つある場合は、カンマ（,）で区切る。

2. オペランドの指定方法
2-1. レジスタ

以下のレジスタ名を使用する 。

    汎用: A, B

    インデックス: X（メモリアクセス時のオフセット計算に使用）

    スタックポインタ: SP

    プログラムカウンタ: PC（参照専用）

    フラグ: FLAGS

2-2. 即値（Immediate）

数値の前に # を付与する。

    例: #0x1234, #100

    サイズは16bit（imm16）として処理される 。

2-3. メモリ参照（Indirection）

メモリ内容を参照する場合は [] で囲む 。

    絶対アドレス: [0x1000]（指定したアドレスの内容）

    レジスタ間接: [A]（レジスタの内容をアドレスとして参照）

    インデックス修飾: [X + #0x0010]（Xレジスタに即値を加算したアドレスを参照） 

3. 命令一覧（Mnemonics）

ISA2.0.txtを参照のこと。


4. ラベルとディレクティブ
4-1. 通常ラベル

    ラベル名: の形式で記述し、その位置のアドレスを保持する。

4-2. アセンブラ・ディレクティブ

アセンブラへの指示を行う特殊命令。

    .org アドレス: 以降の命令を配置する開始アドレスを指定する。

    .vector 種類 アドレス: 割り込みベクタを設定する。

        種類には reset や irq0 などが入る。

5. プログラム例


.vector reset 0x0000
.vector irq0  0x0010

.org 0x0000
start:
    LDW X, #0x1000    ; Xレジスタの初期化
    EI                ; 割り込み許可
loop:
    LDW A, [X + #0]   ; Xのアドレスからロード
    CMPI A, #0        ; Aが0か比較
    BEQ end           ; 0なら終了
    JMP loop          ; ループ継続
end:
    HALT

.org 0x0010
irq0:
    ADDI B, #1        ; カウントアップ
    IRET              ; 割り込み復帰
