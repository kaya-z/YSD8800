### 2.5.1 ★★M-3 是正：観測手段は是正によって無効化される★★

`sd_buf_ptr` は **C の変数であり `mem[]` 配列上に存在しない**（L968 `static uint16_t sd_buf_ptr`）。

★**しかし v2.14 では `dbg_rd16()` → `phys_rd8()` → `mem[0xFCA8]` の直読となり、`sd_buf_ptr` は読めない。**★

| 版 | `memw <SD_DATA>`×5 → `memw <SD_BUF_PTR>` | 何を示すか |
|---|---|---|
| v2.13 | +5 進む | ✅ 副作用の存在を正しく実証 |
| v2.14 | 不変 | ❌ ★**副作用が消えたからではなく、観測手段が壊れたから**★ |

| **v2.14** | `sd_buf[0]` の値 | ★**是正：デバッガ操作が実行結果に影響しない**★ |

**★対照成立の前提条件（段0 で先に確認する）★**

### 3.3 照合規則の正式定義

`cmd_is()`（v2.13・L2729）は**廃止せず残す**（KY41）。

```c
/* ★[v2.14 MW-1] REPL キーワード照合（設計書 §3.3）★
 *   kw 直後が 区切り(NUL/空白/改行) → 通常形
 *   kw 直後が 数字 or '$'           → 区切り無し引数形（後方互換・§3.2）
 *   kw 直後が それ以外（英字・'-' 含む）→ ★不一致。これが順序依存を消す★
 *
 * ★'-' を許容しない理由（M-4 案b）★
 *   %d は符号を受理するが、負の step 数/BP番号/IRQ番号は無意味であり
 *   後段で弾かれる。s-5 等は Unknown となる（§3.2 の破壊リストに記載済）。
 * ★'$' を許容する理由★
 *   現時点で救われるコマンドは無い（%hx は '$' を読めないため
 *   b$1000 は v2.13 でも "Unknown label: $1000" になる）。
 *   将来 REPL の <addr> 書式を setb 系（emu23_memwrite_design §3.2 が
 *   '$'/'0x'/裸16進を許容）へ揃える意図で先行して許容する。
 * ★'0x' 前置は isdigit('0') が真のため自動的に許容される★ */
static const char *repl_kw(const char *cmd, const char *kw)
{
    size_t n = strlen(kw);
    unsigned char c;
    if (strncmp(cmd, kw, n) != 0) return NULL;
    c = (unsigned char)cmd[n];                 /* ★N-3: 負値UB回避★ */
    if (c == '\0' || c == ' ' || c == '\t' || c == '\n' || c == '\r')
        return cmd + n;
    if (isdigit(c) || c == '$') return cmd + n;
    return NULL;
}
```

### 4.1 是正の方向（★先に固定する・KY61★）

### 4.2 新設する経路

```c
/* ★[v2.14 MW-2] デバッガ由来のバイト読み出し★
 * MMU 変換は行うが MMIO ディスパッチを行わない。
 * → SD_DATA 等の読み出し副作用・未マップ警告が発生しない。
 *
 * ★dbg_access を立てていないのは付け忘れではない（v0.1レビュー C-1）★
 *   phys_rd8() は L326-329 で配列を直読するのみで mem_charge() を
 *   通らないため、課金・統計・トレースは原理的に発生しない。
 *   ここでフラグを立てると、外側の dbg_access 区間(7箇所)の内側から
 *   呼ばれた際に★内側の =0 が外側の抑止を解除する★事故を招く。
 * ★このコメントを消さないこと。消すと後日「親切に」足される。★
 *
 * ★副作用が無い代償（§4.5）★ MMIO レジスタの内容は読めなくなる。
 *   sd_buf_ptr 等は C 変数であり mem[] 上に存在しない（§2.5.1）。 */
static uint8_t dbg_rd8(uint16_t la)
{
    uint32_t pa = mmu_mode ? mmu_translate(la) : (uint32_t)la;
    return phys_rd8(pa);
}

/* ワード合成の単一実装（★2実装の統合★）
 * バイト順は LE（rd16() L1409〜 と同一）
 * ★(uint16_t) キャストはラップが意図的であることを示す（N-1）★ */
static uint16_t dbg_rd16(uint16_t la)
{
    uint8_t lo = dbg_rd8(la);
    uint8_t hi = dbg_rd8((uint16_t)(la + 1));
    return (uint16_t)((hi << 8) | lo);
}
```
