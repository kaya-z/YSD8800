### 3.3 照合規則の正式定義

`cmd_is()`（v2.13・L2729）は**廃止せず残す**（KY41）。新ヘルパを追加する。

```c
/* ★[v2.14 MW-1] REPL キーワード照合（設計書 §3.3）★
 * 返り値 = 引数開始位置 / NULL = 不一致
 *   kw 直後が 区切り(NUL/空白/改行) → 通常形
 *   kw 直後が 数字 or '$'           → 区切り無し引数形（後方互換・§3.2）
 *   kw 直後が それ以外（英字含む）  → ★不一致。これが順序依存を消す★
 * ★'0x' 前置は isdigit('0') が真のため自動的に許容される★ */
static const char *repl_kw(const char *cmd, const char *kw)
{
    size_t n = strlen(kw);
    unsigned char c;
    if (strncmp(cmd, kw, n) != 0) return NULL;
    c = (unsigned char)cmd[n];                 /* ★N-3: 負値UB回避★ */
    if (c == '\0' || c == ' ' || c == '\t' || c == '\n' || c == '\r')
        return cmd + n;
    if (isdigit(c) || c == '$') return cmd + n;
    return NULL;
}
```

`<ctype.h>` の include 有無を実装時に確認する。

```c
/* ★[v2.14 MW-2] デバッガ由来のバイト読み出し（設計書 §4.2）★
 * MMU 変換は行うが MMIO ディスパッチを行わない。

 *   ここでフラグを立てると、外側の dbg_access 区間(7箇所)の内側から
 *   呼ばれた際に★内側の =0 が外側の抑止を解除する★事故を招く。
 * ★このコメントを消さないこと。消すと後日「親切に」足される。★ */
static uint8_t dbg_rd8(uint16_t la)
{
    uint32_t pa = mmu_mode ? mmu_translate(la) : (uint32_t)la;
    return phys_rd8(pa);
}

/* ワード合成の単一実装（★M-2：2実装の統合★）
 * バイト順は LE（rd16() L1409〜 と同一。§2 で確認済）

static uint16_t dbg_rd16(uint16_t la)
{
    uint8_t lo = dbg_rd8(la);
    uint8_t hi = dbg_rd8((uint16_t)(la + 1));
    return (uint16_t)((hi << 8) | lo);
}
```

| 非 MMU `mem` | `mem[a]` | `phys_rd8(a)`→`mem[(uint16_t)a]` | ★恒等・byte-exact★ |

★**G-4（`-q` stdout byte-exact）**★：`dump_mem`/`dump_memw` は REPL 専用だが、★**CLI `-d` は `-q` と併用されうる**★（レビュー M-2-3）。したがって **G-4 は `-q` 単独だけでなく `-q -d <非MMIO帯>` の組み合わせでも確認する**（§6.2 T-2-8）。非 MMU・非 MMIO 帯では恒等のはずである。

### 4.5 失われる挙動（★C-3 反映★）

`memw` / CLI `-d` の未マップ帯読み出しで**消えるもの**：

1. `mmio_report_unmapped()` の警告表示
2. `bus_pullup_enabled` 時の `0xFF` 合成（L1424-1441）

**代替手段の現状**

| 手段 | 可否 |
|---|---|
| `physmem` | ★**不可**★。物理直読のため**合成前の値**が見える＝プルアップの効果は観測できない。かつ `--mmu` 時のみ有効 |
| 実行経路（プログラムから読む） | 可能だが `_poc` asm が増え続ける（`emu23_memwrite_design` §1.2 の問題） |

★**起票：MW-6**★ — MMIO 帯を**実機同等の経路で 1 回だけ読む**専用コマンド（仮称 `peek`）。**副作用があることを明示したうえで意図的に発火させる**コマンドであり、`mem` 系（観測が対象を変えない）とは責務が異なる。**本版には含めない（KY58）。** `kaizen.txt` の未決起票へ登録する。

## 9. 却下した案（★記録・削除しないこと★）
