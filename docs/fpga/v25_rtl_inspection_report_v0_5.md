## 3. 所見一覧（v0.5更新分）

### 3.1 S-1（TKT-V16 (a)〜(d)）＋S-2候補（e）

| ID | 内容 | TKT |
|---|---|---|
| G-001〜RV-1 | （変更なし） | TKT-V16(a)(b)(c) |
| X-1 | `cpu_clk`周波数依存定数（UART・Timer・SD）とPLL未設計の不整合 | TKT-V16(d) |

**Y-2是正：X-1のリスク記述**

v0.4の「SD初期化SCK（200kHz）が規格上限（400kHz）に近い」は不正確でした。実際には200kHzは規格範囲100-400kHzの**中央**であり、規格外となるのは`cpu_clk`が**8MHzを超えた場合のみ**です。ご指摘の通り、真に厳しい制約はUARTの1xサンプリング方式（`ysd8001_uart_design_v1_3_2.md` §12.4 C-28：許容偏差は公称417サイクルに対しp_lo=394〜p_hi=440＝概ね±5.5%）であり、SDより先にPLL誤差の影響を受けます。リスクは「①将来クロックを上げること（`ysd8002_timer_design`ヘッダに『FPGAの限界まで（将来）』と明記済）、②PLL出力誤差がUARTの±5.5%許容を超えること」の2点に整理しました。

**G-006（新規・TKT-V16(e)）**：`SPI_TIMEOUT`=2,000,000サイクル（4MHzで0.5秒）は、周波数の整合とは独立に、**値そのものがSD Physical Layer仕様の要求水準に達していません**。Web検索で確認したところ、SD Physical Layer Simplified Specification §4.2.3は「ACMD41は最低1秒試行すること」と規定しており（NXP・mbed・AVR等、複数の独立した実装事例で同一の記述を確認）、現行値はこの半分です。クロックが正確に4MHzちょうどであっても、規格上正当な低速カードの初期化を誤ってERROR扱いする恐れがあります。ご指摘の通り(d)とは別種の問題（周波数整合ではなく値そのものの適正化）のため、TKT-V16(e)として分離しました。

### 3.2 S-2候補・S-3候補（Y-1是正）

**D-201の拡充**：3点の見積りを追加しました。

| 見積り | 値 |
|---|---|
| モデル実測値（下限） | 約16,800サイクル（`ysd8003` L18） |
| 実カード典型値（参考） | 読出待ち(Nac)がms単位、初期化(ACMD41)が数百ms単位になりうる（KY107：モデルはこれらをほとんど模擬していない） |
| SPI_TIMEOUT上限 | 2,000,000サイクル（0.5秒） |

**起動時アクセスの確認**：`mmio_trace.log`でcycle=366,344にSD_CMD書込を確認しました。M-4（プロンプト・cycle=320,156）の直後、**YUI OS起動シーケンスの一部として自動的に**SD初期化が行われています（ユーザー操作起点ではありません）。

**タイマー結論の是正**：「モデルでは単発ストールが1周期未満のため取りこぼし無し」は**モデル上の結論に過ぎません**。実カードの初期化・読出し待ちがモデルより大幅に長くなれば、tickを失う（時刻がずれる）可能性があります。起動時に自動実行される初期化中のストールが実カードで長時間化した場合、**起動直後のタイマーtick喪失は実際に起こりえます**。UART側はS-2候補、タイマー側はS-3候補として別々に判定しました。

**y-4是正**：D-201はTKT-V16(d)には含めず、**TKT-V14（RX FIFO・フロー制御）を主たる関連先**としました。(d)は「周波数整合」、D-201は「wait-stateアーキテクチャの副作用」であり、種類が異なるためです。

### 3.3 y-5・y-6

**y-5**：引用文献の拡張子誤りを是正しました。3文書のうち`ysd8002_timer_design`のみ実体が`.md`（E-005既出）で、`ysd8001_uart_design`（`.md`）・`toolchain23_design`（`.docx`、Drive確認済）は台帳L830の表記どおり正しいことを確認しています。

**y-6**：membusの`cycle_r`は`dbg_cycle`（診断専用）に加え`ysd8002.cycle_i`にも供給されますが、現行YUI OS（カーネルasm・forth両方）はCYCLE_LO/HIを一切参照していません（grep 0件）。現状は機能への影響がないため、4系統の周波数依存定数から分離し参考記録としました。
