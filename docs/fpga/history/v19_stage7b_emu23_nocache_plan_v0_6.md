### 3.2 課金式（★新設分★）

```
読み（F/R8/R16）: lat[kind] - 1
書き（W8/W16）  : lat[kind] - 1
```

★根拠★：RTL の `CEN=0` では `cache` が純バイパスとなり、CPU の各アクセスが
`cdc_bridge` 経由で ★単発アクセス★ として PSRAM に到達する。★ラインフィルは発生しない★。

★`-1` の由来は現行4分岐と同一（PSRAM 応答の 1 サイクルは CPI 側に含まれる）。
新設分だけ規約を変えてはならない。★

> ★注意（v0.3）★：この `−1` は ★課金規約★ である。
> ★§4.3.3 のキュー模擬で用いる「メモリ占有時間」とは別物であり、混同してはならない。★

#### 3.2.1 16bit アクセスの対応（C-3）

emu23 は 16bit アクセスを ★呼出側がバイト単位で 2 回★ `mem_charge()` する
（L1567-1568 読み／L1731-1732 書き）。RTL 側も ★8bit バスの 2 トランザクション★ であり
★対応は取れている★。したがって `lat[RD8]`＝`lat[RD16]`、`lat[WR8]`＝`lat[WR16]` でなければ
物理的に不整合である（emu23 自身も L720-725 で警告する）。

### 3.3 実装方針

- ★`mem_charge()` の中に分岐を 1 つ足すだけ★とし、関数を分割しない
- 分岐位置は ★L781（`dbg_access`）より後ろ★（U-3）。フックを MMIO 分岐より前へ動かさない（§2.2）
- `nocache_model` 時は ★`cache_valid[]`／`cache_tag[]` を一切触らない★
- `stat_hit`／`stat_miss` は全件 miss として計上する（§3.4 で明示表示）
- トレースの `hit` 欄は常に 0 になる

#### 3.3.1 kind 別呼出回数カウンタの新設（M-3）

`lat_eff`／連立の母数に ★`mem_charge()` の呼出回数★ が要る。
★`stat_hit`／`stat_miss` は `nocache_model` 時に全件 miss となり母数として使えない。★

```
static unsigned long stat_calls[6];   /* acc_kind_t 別。★常時計上★ */
```

- 計上位置は ★`dbg_access` 判定の後・課金分岐の前★
- ★`charge_enable==0` でも計上する★（判定・記録のみの状態でも母数は必要）
- 出力は `--cache-stats` に 1 行追加

★あわせて命令数 `I` も出力する（§5.1 の連立に必要）。`cpu.cycle` は
`-mc` および課金により歩進量が変わるため、★命令実行回数の独立カウンタを設けること。★
