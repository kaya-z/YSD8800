## §3. 論点A — UART_BAUD 実分周

### 3.1 分周器の仕様（★A-3 是正★）

| 項目 | ~~v0.2~~ | ★v0.3★ |

| 1ビット周期 | ~~`baud_div = (baud_r==0) ? 1 : baud_r`~~ | ★`baud_div = baud_r + 1`（17bit）★ |
| `baud_r = 0` | ~~1 にクランプ（R-4）~~ | ★**特殊処理なし**。周期 1 に自然に落ちる★ |
| カウンタ幅 | ~~16bit~~ | ★**17bit**（`baud_r=65535` で周期 65536）。最低 61bps@4MHz★ |
| 反映タイミング | バイト境界でラッチ | 同左（`baud_div_tx_lat` / `baud_div_rx_lat`） |
| RX 成立下限 | ~~`baud_div ≧ 8`~~ | ★`baud_div ≧ 8` ＝ **`baud_r ≧ 7`**★ |

| # | 理由 |
|---|---|
| (a) | 上位仕様 §8 がドライバは同式で値を計算する前提。仕様と実装を乖離させない |
| (b) | 4167 との差が小さい（−7 → +3） |

### 7.1 M-4 の期待値の導出（承認済）と★観測規約（B-10）★

★観測規約：TB は `stat_r[0]` を**エッジ N の直前（エッジ N−1 と N の間の negedge）**でサンプルし、
その値を「エッジ N で観測された値」とする。すなわち NBA 更新前の値を見る。★
★`@(posedge clk); #1;` 型の読出しは使わない（同一波形で N が 1 小さく出る）。★

| エッジ | 事象（C-0） |
|---|---|
| N=0 | `wr_tx=1`。`tx_cnt_r <= 4167`、`stat_r[0] <= 0` |
| N=k | 観測値 `tx_cnt_r = 4167 − (k−1)` |
| N=4167 | `tx_cnt_r = 1` → `tx_done = 1` |
| ★N=4168★ | ★`stat_r[0] = 1` を観測する最初のエッジ★ |

★C-2（`baud_r=416`）★：10×417 = 4170 で完了＋復帰1エッジ → **N=4171**（+3 は §2.2 の差と一致）。
★実装はこの期待値に合わせ、`tx_done` をストップビット最終サイクルで立てる（C-0 の `tx_cnt_r==1` と同じ位相）。★
TB には導出を書き写さず、期待値のみ数値で与える（原則67）。

### 7.2 M-5 の順序関係（★C-11 是正★）

受信確定（stop 中央）は送信完了（stop 終端）より約 0.5 ビット先行する。
★C-2・`baud_r=416` での先行量の合格範囲：`tx_done` − `rx_valid_phy` = **205〜211 サイクル**★
（0.5×417 ≒ 208、これに RX 側 2 段同期＋エッジ検出の遅延 2〜3 サイクルを差し引く方向で幅を取る）。
★逆転（`rx_valid_phy` が後）していればサンプル位相のバグ。★ 範囲外は FAIL とせず要調査として記録する。
