## 3. 総評

3回のレビューで、次の3点が一次資料または実源の根拠つきで確定した。
- PLL の選定基準と、4MHz ちょうどが得られない場合の代替経路
- 周波数に依存する定数を `CPU_HZ` から導出すること（4MHz でビット一致を回帰ゲートとする）
- SD のタイムアウトの初期化用／EXEC 用の分離と、それに伴うストール延長のトレードオフ

誤った根拠を消さずに訂正の履歴として残す運用も定着している。
