## 2. ★M-1 クローズ：論点B の再設計は正しい★

### 2.1 V5（直結）と V6（集約）の構造的差異を正しく捉えている

v0.3 の核心は、stor 割込を「YSD8003 がパルスを出し、YSD8004 が保持・W1C・レベル出力を担う」構造にしたこと。これが正しい理由を、V5 タイマーとの対比で整理する：

| | V5 タイマー | V6 stor（v0.3） |
|---|---|---|
| 系統 | IRQ0 **直結** | IRQ1（**YSD8004 集約**） |
| 保持の責務 | デバイス自身（**レベル必須**） | **YSD8004**（デバイスは**パルスでよい**） |
| クリア契機 | irq0_ack（CPU受理・**1対1**） | **W1C**（ハンドラが IRQ_STAT に書く・**発生元別**） |

★重要な洞察：V5 で「パルスだと S_IRQCHK で取りこぼす→レベル化」としたのに、V6 でパルスに戻して良いのは、**保持の責務が『デバイス自身』から『YSD8004 集約器』へ移るから**である。タイマーは CPU 直結ゆえデバイス自身がレベル保持せねばならなかったが、stor は YSD8004 が bit1 にラッチ保持する。取りこぼしは YSD8004 が防ぐ。★ この違いを v0.3 は正しく踏まえている。

### 2.2 実照合による裏付け

**OS 側（発生元区別 W1C）** — `kernel_v12_7.asm`：
- L132「IRQ1_HANDLER 拡張: **bit1 (STOR) 分岐追加**」
- L290「**IRQ1_WK_STAT（IRQ_STAT保存用、複数bit同時処理対応）**」
- → OS の IRQ1_HANDLER は IRQ_STAT を読んで bit0(RX)/bit1(STOR) を判別し、複数 bit 同時にも対応。W1C で発生元別にクリアする。v0.3 の主張「OS は発生元をきちんと区別している」は正しい。

**W1C 機構** — `emu23_v109.c` L761 `irq_stat &= ~v`：
- ハンドラが bit1 を書けば bit1 だけクリア、bit0 を書けば bit0 だけ。**発生元別クリアが可能**。CPU の一括 irq1_ack では実現できなかったこの選択的クリアが、W1C なら自然に成立する。

**stor 発火** — `emu23_v109.c` L742 `ysd8004_raise(IRQ_STAT_BIT_STOR)`：
- stor 完了で YSD8004 の IRQ_STAT bit1 をセット。v0.3 の「YSD8003.irq_stor_o → YSD8004.irq_src_stor」経路と一致。

### 2.3 v0.3 確定方針の評価（5項目すべて妥当）

1. **irq_stor_o を1クロックパルスへ修正**：YSD8004 のパルス入力規約に合わせる。保持は YSD8004 が担うため取りこぼさない。妥当。
2. **irq_stor_ack 未使用**：CPU irq1_ack 駆動を廃止。YSD8003 内クリアは EXEC 再発行時の自前リセットで足りる。妥当（保持は YSD8004 責務なので YSD8003 は ack 不要）。
3. **irq_stor_o → irq_src_stor 内部直結・YSD8004 無改修**：V3.7 で確立した経路の再利用。V4 UART(RX/TX) が既にこの方式で実動作している前例に載せる判断は的確。
4. **クリア契機＝ハンドラの W1C**：既存 MMIO 経路（$FCB2 への STW）で届く。新規配線不要。
5. **CPU 改変・membus irq1_ack 透過ともに不要**：★前回回答書§4で予見した通り。82ベクタ再回帰も回避できる。★ CPU 無改修が維持され、デグレ範囲が消える。

### 2.4 KY41 の運用も適切

旧案（irq1_ack）を取り消し線で保持し、W1C ベースへ改訂した記録の残し方は KY41 に忠実。「なぜ irq1_ack を否認したか」の理由（IRQ1 集約系統・発生元非区別）も明記され、将来の再発防止になっている。

## 3. 論点A・C（前回承認・変更なし）

- **論点C（ready 合流 L398 1行）**：前回承認。案(D) の正しい実装。★前回付与した条件「SPI タイムアウトで ERROR 確定し ready を返す（永久ストール回避）が YSD8003 v0.2 に実装済みか結合前に再確認」は引き続き有効。★ mmio_ready がこのデバイスで初めて 0 を返すため、ハング経路が無いことの保証を Step1 で確認すること。

## 4. 実装前の最終チェックリスト

v0.3 で全論点クリア。実装（§5-6）着手前に以下のみ確認されたい：

1. **（論点C条件）YSD8003 v0.2 の ready_o に SPI タイムアウト→ERROR→ready 返却が実装済みか。** 未実装なら結合前に追加（永久ストール回避）。
2. **irq_stor_o のパルス化修正**：現状レベル出力（`assign irq_stor_o = irq_req_r`）を「完了時1クロックパルス」へ。この修正が YSD8003 単体 TB（前回全 PASS）を壊さないか、単体 TB の割込項目（T4）を再確認すること。パルス化は T4 の期待値（レベル→パルス）を変える可能性がある。
3. **KY60 の grep 再確認**（結線後の旧版混入ゼロ）。
4. **Step4 全回帰**：CPU 無改修ゆえ V1-V5 系は無破壊のはずだが、mmio_stub/membus 改版の影響で既存ペリフェラル（UART/Timer）アクセスが変わっていないことを確認。

> 特に項目2（irq_stor_o パルス化が単体 TB T4 を壊さないか）は、v0.3 で新たに生じた変更点であり、見落としやすい。YSD8003 単体 TB は「レベル出力＋ack クリア」前提で組まれているはずなので、パルス化に伴い T4 の期待値更新が要る可能性が高い。1変更1検証で慎重に。

## 5. 総合判定

**承認（M-1クローズ）。全論点クリア。原則43により実装着手可。**

- **論点B（M-1）**：★クローズ。W1C/パルス方式(B-2)は、IRQ1 集約系統の割込クリアを正しく YSD8004 の W1C に委ね、YSD8003 はパルス出力に徹する。V5 直結との構造差を正しく捉え、CPU 無改修・82ベクタ再回帰回避を実現。実照合（kernel IRQ1_HANDLER の STOR 分岐 L132・W1C L761・stor 発火 L742）で全裏付け。★
- **論点A**：承認（変更なし）。
- **論点C**：承認（SPI タイムアウトのハング回避確認を条件として維持）。
- **実装前チェック**：irq_stor_o パルス化が YSD8003 単体 TB T4 を壊さないかの再確認（新規変更点）。

M-1 の再設計は的確で、前回指摘の本質を完全に捉えている。実装（Step1-5）へ進んでよい。

> **kaizen 追記（原則79 の実証例として）**：本件は「集約系統の割込クリアは集約器の W1C に委ねる」という原則79を、実際の再設計で体現した好例。V5(直結・レベル・ack) と V6(集約・パルス・W1C) の対比を kaizen.txt に残すと、将来のペリフェラル追加時の設計指針になる。
