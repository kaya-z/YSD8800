## 3. 特記事項（高く評価する点）

### 3.1 (P1-G5) の網羅性論証（M-2）

(P1-G5) の「除外対象が BEQ/BNE/BLT/BGE の4命令で必要十分」という論証が、ISA2.3 実仕様で以下まで裏取りされている点は網羅性として過不足がない（KY34/KY39）。

- Z/N を**読む**のは条件分岐4種のみ（`ISA2_3_v231.docx` L228–231）。`JMP`/`JSR`/`RET` は無条件でフラグを読まない。
- **フラグをレジスタへ移す命令（MC6809 の `TFR CC,r` / `PSHS CC` 相当）が ISA2.3 に存在しない**ことを確認 → フラグ値が分岐以外の経路で観測される抜け道が無い。
- 割り込みは FLAGS を push 退避し `IRET` で pop 復元するため Z/N 可視性に透過的。

これにより「`ADDI SP,#2` の FLAGS 更新値を後続が使う経路」を構造的に全閉塞できることが示されている。MC6809 の CC レジスタ挙動（条件コードがスタックやレジスタ経由で可視化され得る）を踏まえた抜け道潰しであり、妥当。

### 3.2 局所安全性の土台が S2 にも一貫適用された（M-1）

「4命令窓は SP 収支ゼロ・`[SP]`（SP−2番地）自己完結・窓内に SP 相対/分岐/JSR 構造的に不在」という局所論証により、**窓の外側がネスト往復の途中でも局所正味効果は `B=A` で閉じる**ことが明記された。これは指摘書 M-1 の対応案と一致し、「境界偶然マッチ」新前提と矛盾しない一貫した安全性の土台になっている。

### 3.3 ガード体系 G1〜G5 の整合

G1（完全隣接）／G2（SUBI・ADDI 同量）／G3（STW A・LDW B）／G4（`[SP]` オフセット無し）／G5（直後フラグ依存分岐除外）は役割が明確で重複がない。G4 が「窓内の SP 相対」を、G5 が「窓直後のフラグ依存」を担い、§4 S5（区間内 SP 相対介在）とも二重化せず整合している。
