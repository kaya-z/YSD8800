## 4. 総評

5回のレビューを通じて、次のものが検出され、S-1 は4件、S-2 は2件に確定した。いずれもシミュレーションだけでは見えない「FPGA で動くか」という基準の抜けである。
- PSRAM の物理I/F の欠落
- クロック周波数に依存する定数
- SD のタイムアウト値の規格不適合
- wait-state による割込の遮断

途中でレビュア側の誤りも2件あった（r1.0 M-5、r1.0 rv-6）。どちらも、一次資料を読める状態にありながら機能説明や目録だけを根拠にしたことが原因である。点検者とレビュアに共通する教訓として、原則110・原則147 の運用に反映することを推奨する。
