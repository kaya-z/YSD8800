## 4. レビュー確認事項(1)-(5)の最終確定

一次レビュー時に「妥当」とした確認事項について、r2で補記が入り確定した。

| # | 確認事項 | 確定所見 |
|---|---------|---------|
| (1) | sub-opcode 0x18/0x19 の割当 | 妥当。現行 emu23_v109 実ソース照合で 0x10-0x17（LDB/STB）までしか使用しておらず 0x18/0x19 は未使用。0x50台特殊レジスタ予約との衝突なし |
| (2) | FLAGS 不変の方針 | 妥当。既存スタック系（PUSH/POP/PUSHM/POPM/XCHG_SP）と一貫 |
| (3) | rB=SP 時の非推奨扱い | 妥当。POP/PUSH等価を許容しデコーダを特別扱いしない簡潔方針 |
| (4) | プリデク時アライメント判定＝減算後アドレス | 妥当。実アクセスアドレスと一致。C-3で例外時rB状態（減算済・ストア中止）を明記済 |
| (5) | ポストインク FPGA 案A/案B の実装フェーズ送り | 妥当。C-2で案A採用時の注記を追加済 |

## 5. 特記事項（評価点）

一次指摘を上回る品質で反映された箇所を記録する。

1. **C-3の非対称記述**：ポストインクリメント（読み→rB+2）は更新前アドレスで
   例外に入るため rB 未更新、プリデクリメント（rB-2→書き）は減算後アドレスで
   アクセスするため rB 減算済み、という挙動差を、それぞれの動作順序から
   正しく導出し明記している。6809 の ,U++ / ,--U の例外時挙動と整合し、
   FPGA のライトバック抑止条件（ポストインク=両抑止／プリデク=rB更新有効・
   ストア抑止）まで書き下せている。実装者が迷う余地がない。

2. **C-4の移植性配慮**：ABI但し書きにとどまらず「RSP は YUI OS 側で抽象化し
   ISA仕様に固定しない」と明記。YUI OS の複数アーキテクチャ移植性方針と直結する。
