## 3. 指摘事項（軽微のみ・非ブロッカー）

### E（軽微）

#### E-4：§3.5.4 PoC 表の用語が C-3 確定と不整合

§3.5.4 の PoC 実証結果表に「forth load_addr=$5100 **自動配置** ✅」とある（L425 相当）。これは v2.0 時点（has_org 導入前）の PoC ログ表現がそのまま残ったものと思われるが、C-3 確定後の正しい用語は「**固定配置（has_org=1）**」である。$5100 は `.org $5100` 由来で has_org=1 となり固定配置されるのが確定仕様であり、「自動配置」は誤解を招く。**表の文言を「load_addr=$5100 固定配置（has_org=1）」に修正**を推奨。実害はない（PoC 当時の結果記録としては事実）が、確定仕様との用語統一のため。承認ブロッカーではない。

> 補足：もし PoC が has_org 導入前のコードで「load_addr を読むが has_org 判定なし」で通っていたなら、本実装（has_org 判定あり）での再確認が望ましい。§6 実装ステップ T9 で has_org=1 経路として再検証されるので、テスト計画上はカバーされている。
