## 4. 運用ルール

- ツールを改修・更新したら、本台帳の §1 現行版と該当ツールの系譜表を更新する。
- ツール改修時は回帰チェック（Dhrystone）を実施（Force 改修時は対象外）。
- ツールのバナー／ソース VERSION 定義と本台帳の版数が一致することを定期確認する（記憶に頼らず grep で実体確認）。
- 現行版の更新時も、過去版の系譜記録は欠落させない。
