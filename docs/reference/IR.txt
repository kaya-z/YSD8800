以下にscc22  IR導入の方向性を示す。2026/4/5(V1.0)


方式① + 方式②の中間で行く。

式は完全にIR化
文は軽め（if/whileはそのままでもOK）
3アドレス風に分解
最適化なし

----
方式① 最小IR（式ツリー or 3アドレス風・最適化なし）

内容
・式だけIR化（文はそのままでもOK）
・ノード例：
     ADD, MUL, SHL
     LOAD, STORE
     INDEX2D
・コード生成はIR→アセンブリ

変更範囲
・parse_expr() を「値を返す」→「IRノードを返す」に変更
・gen_*系をIR生成に置換
・最後に emit(IR) を追加

----
方式② 実用IR（基本ブロック＋3アドレスコード）

内容
・典型的なTAC（three-address code）

例：
  t1 = i * 50
  t2 = t1 + j
  t3 = t2 << 1
  t4 = base + t3
  store t4, value

追加要素
・仮想レジスタ（t1, t2…）
・簡易レジスタ割当（A/B/X）
・basic block管理
