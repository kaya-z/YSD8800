### 1.3 再現方式

実機で組3／組4 が成立する経路は次の3段である。

```
(a) タスクA が SYSCALL で保存される（saved_a/saved_b = 0 が書かれる）
(b) タスクA が READY 化される（wake_* 等の外部要因）
(c) 復元経路がタスクA を再開する   ← 組3: _sched_found / 組4: _sc_found
```

`TASK_SLEEP` は `state=SLEEPING(3)`（L660-661）で自らは起きないため、
**(b) を PoC が代行する**（実機で `wake_uart_waiter` 等が行う操作と同一）。
**(a) と (c) は実カーネルコードを無改変で通過させる。**

> **★組3 と組4 の差分は分岐先 1 命令のみ★**
> `_sc_found`（L715）と `_sched_found`（L582）は**入口条件が同一**（`X`=TCB アドレス／`L1_WK_A`=tid）。
> したがって `_w2` のハーネスをそのまま流用し、**最後の `JMP` 先だけを変えれば組4 が測れる**。

### 1.4 実装（`_w2` セクション: 組3）

```
_w2
  ├ DI
  ├ JSR _w5_fillslp                     ; 全TCBを SLEEPING(3) 化（W-5 の共通ルーチンを再利用）
  ├ TCB(tid=2) を「別タスク」役として構築
  │    state=READY(1) / saved_pc=_w2_stage2 / saved_sp=$4770
  │    saved_x=$46E6 / saved_a=0 / saved_b=0 / saved_flags=0
  ├ CUR_TASK=1
  ├ TCB(tid=1)+8/+10 に汚染値 $EEEE を仕込む（「たまたま 0」の排除）
  ├ LDW X,#$46E2                        ; ★疑似DSP（M-5: TASK_SLEEP は入口 X を saved_x に保存）
  └ JSR TASK_SLEEP                      ; (a) 実 SYSCALL 保存部を通過
        └ _sched_common → tid=2 が READY でヒット → _sc_found → _w2_stage2

_w2_stage2                              ; 「別タスク」として実行再開
  ├ DI
  ├ LDW SP,#$477E
  ├ 段階マーカ $D9D9 → $468E            ; (KY 対策2: ハング時の到達点切分)
  ├ TCB(tid=1) の state を READY(1) に書換   ; (b)
  ├ L1_WK_A=1 / X=TCB(1)=$4050          ; _sched_found 入口条件
  └ JMP _sched_found                    ; (c) 実復元経路を通過
        └ IRET で tid=1 の saved_pc へ復帰

_w2_after                               ; = JSR TASK_SLEEP の次命令
  ├ DI
  ├ STW A,[$46A0]                       ; ★判定: A
  ├ STW B,[$46A2]                       ; ★判定: B
  ├ LDW SP,#$477E
  ├ 完走マーカ6 $A5A5 → $4688
  └ JMP _w2b
```

> **★`_w2_after` の求め方★**
> `TASK_SLEEP` は L624 で `[SP]`（＝`JSR` が積んだ戻りアドレス）を `SLP_WK_PC` へ退避し、
> L644-645 で `saved_pc` に格納する。したがって **`saved_pc` = `JSR TASK_SLEEP` の次命令アドレス**であり、
> PoC 側では `JSR TASK_SLEEP` の直後にラベル `_w2_after` を置くだけでよい（**アドレス直値は不要**）。

> **★疑似 DSP の必要性（M-5）★**
> `TASK_SLEEP` は L621 で入口の `X` を `SLP_WK_DSP` へ退避し、L649-650 で `saved_x` に格納する。
> `X` を設定せずに呼ぶと未定義値が `saved_x` 経由で復帰後の `X` になり、**再現性のある試験にならない**。
> 既存 `_w3` も `LDW X,#$46E0` を明示している（L429）。

## 2. W-9: `_sc_found` 復帰時の `SP` が `saved_sp` になること

### 2.1 背景

TKT-04 の 16 B 案は `SP` を触らないため理論上自明だが、**記録価値がある**（HANDOVER §2.4）。
なお **W-5 の PASS 自体が強い間接証拠**である（`saved_sp`=`$46F0` を前提に `[$46F0]` へ置いた
戻りアドレスへ L954 `RET` が正しく飛んだ）。本項目はこれを**直接値として記録**する。

### 2.2 実装（`_w9` セクション）

W-1 と同型。ただし **既存 `_w1`／`_w_setup` は改変しない**（非回帰維持）。

```
_w9
  ├ DI
  ├ JSR _w5_fillslp
  ├ TCB(tid=1) を構築
  │    state=READY / saved_pc=_w9_land / saved_sp=$46F0
  │    saved_a=$1111 / saved_b=$2222 / saved_x=$3333 / saved_flags=0
  ├ [$46F0] に _w9_ret を格納           ; _w9_land が RET する先
  ├ L1_WK_A=1 / X=$4050
  └ JMP _sc_found

_w9_land
  ├ DI
  ├ MOV A,SP
  ├ STW A,[$46A4]                       ; ★判定: 復帰直後の SP
  └ RET                                 ; [$46F0] 経由で _w9_ret へ

_w9_ret
  ├ LDW SP,#$477E
  ├ 完走マーカ7 $B7B7 → $468A
  └ JMP _w10
```

### 2.3 判定

| 項目 | 期待 |
|---|---|
| `$46A4`（復帰直後 SP） | **`$46F0`**（= `saved_sp`） |
| `$468A`（完走マーカ7） | `$B7B7` |

> **注**: `MOV A,SP` の実行自体は `SP` を変更しない。`RET` が成立すること自体も `SP=$46F0` の傍証となる。

## 3. W-10: `saved_flags` 復元の非回帰

### 3.1 検証の狙い

`_sc_found` は L731-732 で `saved_flags` を読み `ORI B,#$80`（IE 強制）したうえで
カーネルスタックへ積み、`IRET` で復元する。**M-5（L743-747）はこの直後に挿入されたため、
flags 復元を壊していないことを確認する。**

### 3.2 ★ISA フラグ定義に依存しない測定法（R-5 承認済）★

| 実行 | 内容 |
|---|---|
| A | `v0.12.11 − M-5`（陰性対照カーネル）で `_w10` を実行し、復帰直後の F を採取 |
| B | `v0.12.11`（本番）で同一の `_w10` を実行し、復帰直後の F を採取 |

**A と B の F が一致すれば、M-5 は flags 復元に影響していない**（＝非回帰）。
W-10 の主旨は「差分の不在」を示すことであり、絶対値解釈は不要。

### 3.3 `saved_flags` の値（★v0.2 変更: C-2★）

| 版 | 値 | 問題／利点 |
|---|---|---|
| ~~v0.1~~ | ~~`$00C1`~~ | **bit7 が既に立っており `ORI #$80` の効果を観測できない** |
| **v0.2** | **`$0041`**（`0100_0001`） | bit7 が落ちているため **`ORI` の効果と非 IE ビットの復元を切り分けられる** |

**切り分け表（参考情報。判定は A/B 一致で行う）**

| 観測される F | 解釈 |
|---|---|
| bit7 立ち＋bit6/bit0 立ち | 正常（`ORI` 動作＋復元動作） |
| bit7 落ち | `ORI B,#$80` の欠落 |
| bit6/bit0 落ち | `saved_flags` 復元の欠落 |

### 3.4 F の採取方法

`emu23` はブレークポイント停止時に `F=xx` を表示する（W-5 実行時に確認済）。
**`_w10_land` の先頭にブレークポイントを置き、レジスタ表示行から F を読む。**
（メモリへの記録は行わない。フラグを読む専用命令に依存しないため。）

### 3.5 実装（`_w10` セクション）

```
_w10
  ├ DI
  ├ JSR _w5_fillslp
  ├ TCB(tid=1) を構築
  │    state=READY / saved_pc=_w10_land / saved_sp=$46F0
  │    saved_a=$4444 / saved_b=$5555 / saved_x=$6666
  │    saved_flags=$0041                ; ★C-2
  ├ [$46F0] に _w10_ret を格納
  ├ L1_WK_A=1 / X=$4050
  └ JMP _sc_found

_w10_land                               ; ★ここに BP を置いて F を読む
  ├ DI
  └ RET

_w10_ret
  ├ LDW SP,#$477E
  ├ 完走マーカ8 $C8C8 → $468C
  └ JMP _w3                             ; 既存 W-3 へ引き継ぐ（現行の終端）
```

### 3.6 判定

| 項目 | 期待 |
|---|---|
| `_w10_land` 到達時の F | **陰性対照と本番で一致** |

```
  → _w3 → JSR TASK_SLEEP → _sc_idle（BP で停止）
```

**`_w5_land` の終端 `JMP _w3` を `JMP _w2` に変更**し、`_w10_ret` の終端を `JMP _w3` とする。

> **★W-5 コードへの介入について（R-6 承認済）★**
> 変更は**終端の JMP 先 1 行のみ**であり、W-5 の判定値（`$46AE`）確定後の位置にある。
> 代替案（`_w3` 先頭に `JMP _w2` を挿す）は、(1) **既に PASS 済みの W-3 のコードに手を入れる**、
> (2) `_w10_ret` の戻り先として `_w3` 内部に新ラベルを起こす必要が生じる——で
> 介入箇所が 2 個所に増え非回帰リスクが高いため、現案を採用する。
> **W-5 の再実行で `$46AE`／`$4686` が不変であることを非回帰として確認する。**

## 6. 実施手順（★v0.2 全面改訂: M-2／M-3／M-4★）

> **★v0.1 の誤り（取消線で保持）★**
> ~~`printf 'b _w10_land\nc\nmem 46a0 16\nmem 4680 16\nc\nq\n'`~~
> **末尾の `c` は `_w10_ret` → `JMP _w3` → `JSR TASK_SLEEP` → `_sc_idle`（無限ループ）へ入り、
> HALT に到達せずハングする。** W-5 レビュー M-9 と同型の見落とし。
> また §8 の KY 対策1（`timeout` 必須）が §6 に反映されていなかった（M-3）。

**BP は 2 個張る**（`emu23` は複数 BP を保持できる）。**指定はラベルで行う**（M-4）。

```bash
# 本番
timeout 120 sh -c "printf 'b _w10_land\nb _w3\nc\nc\nmem 46a0 16\nmem 4680 16\nmem 46e0 16\nq\n' | \
  ./emu23 yuios_vprobe_poc.bin -i uart_empty.bin --disk disk.img" | tr -d '\000'

# 陰性対照（W-10 の F 比較用）
timeout 120 sh -c "printf 'b _w10_land\nc\nq\n' | \
  ./emu23 yuios_negM5_poc.bin -i uart_empty.bin --disk disk.img" | tr -d '\000'
```

| 段階 | 停止位置 | 採取 |
|---|---|---|
| 1 回目の `c` | `_w10_land` | **W-10 の F**（レジスタ表示行から読む） |
| 2 回目の `c` | `_w3` | `mem` で W-2／W-2b／W-9 の判定値と全マーカ |

**ラベル指定を推奨する理由（M-4・C-6）**: `emu23_v111.c` L1704-1723 は 16進／ラベルの**両対応**だが、
W-10 は**本番と陰性対照の 2 バイナリ**で同一手順を回すため、16進直値だと `.sym` を引き直す必要が生じ
取り違えのリスクが増える。ラベル指定なら各バイナリの `.sym` から自動解決される。

**`mem` の引数基数**: アドレス16進・バイト数10進（`sscanf("%hx %d")`）。
`mem 46a0 16` → `$46A0`〜`$46AF`（W-2/W-9/W-2b 判定値＋マーカ9）。
`mem 4680 16` → `$4680`〜`$468F`（マーカ6/7/8＋段階マーカ `$468E`）。
`mem 46e0 16` → 疑似 DSP 帯の確認（参考）。

**`timeout` は必須**（M-3）。W-2／W-2b の失敗は「誤った値」ではなく「無応答」として現れる。

## 8. リスク（KY）

★**危険: `_w2`／`_w2b` は `TASK_SLEEP` から「別タスクとして」戻る二段構成であり、
`_w2_stage2`／`_w2b_stage2` へ到達する前に `_sc_idle` へ落ちる可能性がある。**
別タスク役 TCB の構築を誤る（`state≠READY`、`saved_sp` 不正など）と、
`_sched_common` が READY を見つけられず `_sc_idle`（`EI`/`NOP`/`DI` 無限ループ）に入り、
**BP に到達せず emu23 がハングする**。W-5 と異なり、失敗が「誤った値」ではなく「無応答」として現れる。

→ **対策**:
1. **`timeout` を必ず付けて実行する**（§6 に反映済・M-3）。無応答を有限時間で検出する。
2. **段階マーカを置く**: `_w2_stage2`→`$468E`、`_w2b_stage2`→`$469E`。
   ハング時にどこまで進んだかを切り分け可能にする。
3. 別タスク役の `saved_sp` は `_sc_found` が `SP=saved_sp-4` として使うため、
   **PoC スタック帯（`$477E` から下降）と衝突しない値**（tid=2: `$4770`／tid=3: `$4760`）を割り当てる。
   SP 収支はレビュー N-1 で健全性が実源検証済み。
