## 1. W-2: 組3（SYSCALL 保存 × `_sched_found` 復元）の直接実測

### 1.1 検証対象の組

原則106 系4 に基づく m×n 組。

| 組 | 保存経路 | 復元経路 | 状況 |
|---|---|---|---|
| 組1 | IRQ0 保存（L496-516） | `_sched_found`（L582-610） | ✅ W-4 で PASS |
| 組2 | IRQ0 保存 | `_sc_found`（L715-748） | ✅ **W-5 で PASS**（end-to-end） |
| **組3** | **SYSCALL 保存（L643-659 等）** | **`_sched_found`** | **🔧 本項目** |
| 組4 | SYSCALL 保存 | `_sc_found` | ✅ W-1（合成 TCB）＋ W-3（保存側）で成立 |

**組3 は W-3（保存側で `0` が書かれる）∧ W-4（復元側が `saved_a/saved_b` を復元する）から論理的に成立するが、直接実測していない。**

### 1.2 期待値（YUI OS SYSCALL ABI）

> システムコールを跨いで `A`／`B` は保持されない（caller-saved）。
> **システムコールから復帰したタスクの `A`／`B` は `0` である。**

したがって **期待値は A=`$0000` / B=`$0000`**。

### 1.3 再現方式

実機で組3 が成立する経路は次の3段である。

```
(a) タスクA が SYSCALL で保存される（saved_a/saved_b = 0 が書かれる）
(b) タスクA が READY 化される（wake_* 等の外部要因）
(c) IRQ0 が発生し _sched_found でタスクA が復元される
```

`TASK_SLEEP` は `state=SLEEPING(3)`（L660-661）で自らは起きないため、
**(b) を PoC が代行する**（実機で `wake_uart_waiter` 等が行う操作と同一）。

**(a) と (c) は実カーネルコードを無改変で通過させる。**

### 1.4 実装（`_w2` セクション）

```
_w2
  ├ TCB(tid=2) を READY・saved_pc=_w2_stage2 として用意（「別タスク」役）
  ├ 他TCB(tid≠1,2) を SLEEPING(3) 化
  ├ CUR_TASK=1、TCB(tid=1)+8/+10 に汚染値 $EEEE を仕込む
  └ JSR TASK_SLEEP            ← (a) 実 SYSCALL 保存部を通過
        └ _sched_common → tid=2 が READY でヒット → _sc_found → _w2_stage2

_w2_stage2                     ← 「別タスク」として実行再開
  ├ DI
  ├ TCB(tid=1) の state を READY(1) に書換   ← (b)
  ├ L1_WK_A=1 / X=TCB(1)（_sched_found 入口条件）
  └ JMP _sched_found          ← (c) 実復元経路を通過
        └ IRET で tid=1 の saved_pc へ復帰

_w2_after                      ← tid=1 の saved_pc（= JSR TASK_SLEEP の次命令）
  ├ DI
  ├ STW A,[$46A0]  ← ★判定: A
  ├ STW B,[$46A2]  ← ★判定: B
  ├ 完走マーカ6 $A5A5 → $4688
  └ JMP _w9
```

> **★`_w2_after` の求め方★**
> `TASK_SLEEP` は L624 で `[SP]`（＝`JSR` が積んだ戻りアドレス）を `SLP_WK_PC` へ退避し、
> L644-645 で `saved_pc` に格納する。したがって **`saved_pc` = `JSR TASK_SLEEP` の次命令アドレス**であり、
> PoC 側では `JSR TASK_SLEEP` の直後にラベル `_w2_after` を置くだけでよい（アドレス直値は不要）。

### 1.5 判定

| 項目 | 期待 | 備考 |
|---|---|---|
| `$46A0`（A） | **`$0000`** | 汚染値 `$EEEE` が残れば FAIL |
| `$46A2`（B） | **`$0000`** | 同上 |
| `$4688`（完走マーカ6） | `$A5A5` | 経路到達の実証 |

### 1.6 陰性対照

**不要。** W-2 は「TKT-04 の修正が効くか」ではなく「組3 が ABI どおりに動くか」の確認であり、
M-5 は `_sc_found` 側の修正で `_sched_found` には無関係である（`_sched_found` の A/B 復元は v0.12.6 で既存）。
ただし**汚染値 `$EEEE` を事前に仕込む**ことで、「たまたま 0 だった」という偽合格は排除される。

## 2. W-9: `_sc_found` 復帰時の `SP` が `saved_sp` になること

### 2.1 背景

TKT-04 の 16 B 案は `SP` を触らないため理論上自明だが、**記録価値がある**（HANDOVER §2.4）。
なお **W-5 の PASS 自体が強い間接証拠**である（`saved_sp`=`$46F0` を前提に `[$46F0]` へ置いた
戻りアドレスへ L954 `RET` が正しく飛んだ）。本項目はこれを**直接値として記録**する。

### 2.2 実装（`_w9` セクション）

W-1 と同型。ただし **既存 `_w1` は改変しない**（非回帰維持）。

```
_w9
  ├ 全TCBを SLEEPING(3) 化（_w5_fillslp を再利用）
  ├ TCB(tid=1) を構築: saved_sp=$46F0 / saved_pc=_w9_land
  │                    saved_a=$1111 / saved_b=$2222 / saved_x=$3333
  ├ [$46F0] に _w9_ret を格納（_w9_land が RET する先）
  └ JMP _sc_found

_w9_land
  ├ DI
  ├ MOV A,SP → STW A,[$46A4]   ← ★判定: 復帰直後の SP
  └ RET                         ← [$46F0] 経由で _w9_ret へ

_w9_ret
  ├ LDW SP,#$477E
  ├ 完走マーカ7 $B7B7 → $468A
  └ JMP _w10
```

### 2.3 判定

| 項目 | 期待 |
|---|---|
| `$46A4`（復帰直後 SP） | **`$46F0`**（= `saved_sp`） |
| `$468A`（完走マーカ7） | `$B7B7` |

> **注**: `MOV A,SP` の実行自体は `SP` を変更しない。`RET` が成立すること自体も `SP=$46F0` の傍証となる。

## 3. W-10: `saved_flags` 復元の非回帰

### 3.1 検証の狙い

`_sc_found` は L731-732 で `saved_flags` を読み `ORI B,#$80`（IE 強制）したうえで
カーネルスタックへ積み、`IRET` で復元する。**M-5（L743-747）はこの直後に挿入されたため、
flags 復元を壊していないことを確認する。**

### 3.2 ★ISA フラグ定義に依存しない測定法★

フラグの各ビット意味を特定せずに済ませるため、**陰性対照との一致比較**で判定する。

| 実行 | 内容 |
|---|---|
| A | `v0.12.11 − M-5`（陰性対照カーネル）で `_w10` を実行し、復帰直後の F を採取 |
| B | `v0.12.11`（本番）で同一の `_w10` を実行し、復帰直後の F を採取 |

**A と B の F が一致すれば、M-5 は flags 復元に影響していない**（＝非回帰）。
これは W-10 の主旨（「非回帰」）を過不足なく満たす。

### 3.3 F の採取方法

`emu23` はブレークポイント停止時に `F=xx` を表示する（W-5 実行時に確認済）。
**`_w10_land` の先頭にブレークポイントを置き、レジスタ表示行から F を読む。**
（メモリへの記録は行わない。フラグを読む専用命令に依存しないため。）

### 3.4 実装（`_w10` セクション）

```
_w10
  ├ 全TCBを SLEEPING(3) 化
  ├ TCB(tid=1) を構築: saved_flags=$00C1（★IE以外のビットも立てる）
  │                    saved_pc=_w10_land / saved_sp=$46F0
  │                    saved_a=$4444 / saved_b=$5555 / saved_x=$6666
  ├ [$46F0] に _w10_ret を格納
  └ JMP _sc_found

_w10_land          ← ★ここに BP を置いて F を読む
  ├ DI
  └ RET

_w10_ret
  ├ LDW SP,#$477E
  ├ 完走マーカ8 $C8C8 → $468C
  └ JMP _w3        ← 既存 W-3 へ引き継ぐ（現行の終端）
```

> **`saved_flags=$00C1` とする理由**: `$80`（IE）は `ORI` で必ず立つため、
> **IE 以外のビットが復元されているか**を見るには追加ビットが要る。
> `$40`／`$01` を立てておけば、復元されていれば F に現れ、されていなければ落ちる。
> **ビットの意味は判定に用いない**（A/B 実行の一致のみを見る）。

### 3.5 判定

| 項目 | 期待 |
|---|---|
| `_w10_land` 到達時の F | **陰性対照と本番で一致** |
| `$468C`（完走マーカ8） | `$C8C8` |


## 6. 実施手順

```bash
# 本番
printf 'b _w10_land\nc\nmem 46a0 16\nmem 4680 16\nc\nq\n' | \
  ./emu23 yuios_vprobe_poc.bin -i uart_empty.bin --disk disk.img
# 陰性対照（W-10 の F 比較用）
printf 'b _w10_land\nc\nq\n' | \
  ./emu23 yuios_negM5_poc.bin -i uart_empty.bin --disk disk.img
```

- BP は**ラベルではなく `.sym` から得た16進アドレス**を指定する（W-5 実施時の運用に合わせる）。
- `mem` は **アドレス16進・バイト数10進**。
- `_w10_land` で停止した時点で W-2／W-9 の記録は確定済み。**W-10 の F は停止時のレジスタ表示行から読む。**
- 完走マーカ8（`$468C`）は BP 通過後に書かれるため、`c` で再開してから採取するか、`_w3` に BP を移して採取する。

## 8. リスク（KY）

★**危険: `_w2` は `TASK_SLEEP` から「別タスクとして」戻る二段構成であり、
`_w2_stage2` へ到達する前に `_sc_idle` へ落ちる可能性がある。**
TCB(tid=2) の構築を誤る（`state≠READY`、`saved_sp` 不正など）と、
`_sched_common` が READY を見つけられず `_sc_idle`（`EI`/`NOP`/`DI` 無限ループ）に入り、
**BP に到達せず emu23 がハングする**。W-5 と異なり、失敗が「誤った値」ではなく「無応答」として現れる。

→ **対策**:
1. **`timeout` を必ず付けて実行する**（W-5 実施時と同様）。無応答を有限時間で検出する。
2. **段階マーカを置く**: `_w2_stage2` 到達時にも中間マーカ（`$468E` = `$D9D9`）を書き、
   ハング時にどこまで進んだかを切り分け可能にする。
3. TCB(tid=2) の `saved_sp` は `_sc_found` が `SP=saved_sp-4` として使うため、
   **PoC スタック帯と衝突しない値**（`$4770`）を割り当てる。
