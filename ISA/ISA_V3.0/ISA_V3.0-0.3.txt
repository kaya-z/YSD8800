YSD8800 ISA3.0 仮フリーズ仕様（修正版） V0.3

1. 設計方針
ISA2.2との完全バイナリ互換を維持
拡張命令はプレフィックス 0x1F 配下
コンパイラ（IR + レジスタ割当）前提
シンプルな単サイクル〜軽量パイプライン実装を想定

2. データ幅（確定）
・基本データ幅：16bit
・レジスタ幅：16bit
・スタック操作：16bit単位

👉 これでPUSH/POPとの整合を完全に取る

3. レジスタ仕様

3.1 レジスタ構成（12本）
R0 : A        ; 戻り値 / 演算結果
R1 : B        ; 補助
R2 : X        ; インデックス

R3 : SP       ; スタックポインタ
R4 : PC       ; プログラムカウンタ
R5 : FLAGS    ; フラグ

R6 : T0       ; caller-save
R7 : T1
R8 : T2
R9 : T3

R10: S0       ; callee-save
R11: S1       ; callee-save

3.2 USP（ユーザスタックポインタ）
USP : 特殊レジスタ（非アドレッサブル）
汎用レジスタ番号を持たない
PUSH/POP/PUSHM対象外
以下の命令でのみアクセス可能
XCHG_SP   ; SP ↔ USP

4. スタック命令

4.1 単体PUSH/POP
PUSH rS
POP  rD
4.2 PUSHM / POPM（修正版）
フォーマット（修正済）
byte0 : 0x1F
byte1 : sub-op
byte2 : mask low
byte3 : mask high

👉 16bit mask

sub-op
0x20 : PUSHM
0x21 : POPM
mask定義（16bit）
bit0  : R0
bit1  : R1
bit2  : R2
bit3  : R3 (SP)      ; 使用禁止
bit4  : R4 (PC)      ; 非推奨
bit5  : R5 (FLAGS)   ; 非推奨
bit6  : R6
bit7  : R7
bit8  : R8
bit9  : R9
bit10 : R10
bit11 : R11
bit12-15 : 予約
動作順序
PUSHM : 高bit → 低bit
POPM  : 低bit → 高bit
制約
mask=0 → NOP
SPは禁止
FLAGSは使用非推奨（通常コード禁止扱いでもよい）
